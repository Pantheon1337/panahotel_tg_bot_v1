# HotelBot

Telegram-бот для сотрудников отеля Pana White Moscow, предоставляющий доступ к важной информации и обучению.

## Функционал

### Основное меню
- **Об отеле** - информация об отеле, включая:
  - Номерной фонд (стандартные номера, семейные номера, студии)
  - Питание (меню, халяль)
  - Залы (банкетный зал, конференц-зал, спортзал)
  - Навигация по отелю
  - Обмен валют
  - Парковка
  - Расположение
  - Условия проживания

### Обучение
- **Введение в должность** - базовые сведения о работе в отеле
- **Стандарты обслуживания** - правила и стандарты работы с гостями
- **Руководители отделов** - информация о руководстве отеля
- **Заработная плата** - информация о системе оплаты труда
- **Отпуск** - правила предоставления отпусков
- **Больничный** - порядок оформления больничных листов

### Opera PMS
- **New** - создание новых бронирований
- **Check-in** - процедура заселения гостей
- **Check-out** - процедура выселения гостей

## Установка и запуск

1. Клонируйте репозиторий
2. Установите зависимости:
```bash
pip install -r requirements.txt
```
3. Создайте файл `.env` с необходимыми переменными окружения
4. Запустите бота:
```bash
python main.py
```

## Структура проекта

- `main.py` - основной файл для запуска бота
- `handlers/` - обработчики команд и сообщений
- `keyboards/` - клавиатуры для меню
- `database/` - работа с базой данных
- `img/` - изображения для бота

## Требования

- Python 3.8+
- aiogram 3.x
- SQLAlchemy
- python-dotenv
