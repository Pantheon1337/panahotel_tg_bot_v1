# Hotel Bot - Бот для адаптации сотрудников отеля

Telegram-бот для помощи новым сотрудникам отеля в процессе адаптации, обучения и тестирования.

## Функциональность

- Многоуровневое меню с разделами
- Регистрация новых сотрудников
- Обучение и тестирование
- Управление контентом через админ-панель
- Система вопросов и ответов
- Персонализация на основе должности

## Установка

1. Клонируйте репозиторий:
```bash
git clone [url-репозитория]
cd hotel-bot
```

2. Создайте виртуальное окружение и активируйте его:
```bash
python -m venv venv
source venv/bin/activate  # для Linux/Mac
# или
venv\Scripts\activate  # для Windows
```

3. Установите зависимости:
```bash
pip install -r requirements.txt
```

4. Создайте файл `.env` и добавьте токен бота:
```
TELEGRAM_TOKEN=ваш_токен_бота
```

## Запуск

```bash
python main.py
```

## Структура проекта

```
hotel-bot/
├── main.py              # Основной файл бота
├── config.py            # Конфигурация
├── database.py          # Работа с базой данных
├── requirements.txt     # Зависимости
├── .env                 # Переменные окружения
├── handlers/            # Обработчики команд
├── keyboards/           # Клавиатуры
└── utils/              # Вспомогательные функции
```

## Использование

1. Запустите бота командой `/start`
2. Пройдите регистрацию (имя, должность, дата начала работы)
3. Используйте меню для доступа к различным разделам

## Администрирование

Для доступа к админ-панели используйте команду `/admin` (требуется соответствующий уровень доступа).
